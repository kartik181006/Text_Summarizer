Text Summarizer is an AI/NLP-based web application that automatically converts long text or dialogues into short, meaningful summaries. The project uses a T5 (Text-to-Text Transfer Transformer) model from Hugging Face to understand the input text and generate a concise summary while preserving the important information.

The application is developed using Python, FastAPI, Hugging Face Transformers, PyTorch, HTML, CSS, and JavaScript. FastAPI provides the backend API, while the HTML/CSS/JavaScript frontend allows users to enter or paste text and receive the generated summary directly on the webpage.
